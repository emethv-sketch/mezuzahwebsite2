# Hebrew Academy of Tampa Bay — Mezuzah Sponsorship Campaign

A responsive, navy-blue and champagne-gold campaign landing page. All sponsorship and custom-gift calls to action send visitors directly to the school's official donation page:

https://www.hebrewacademytampabay.org/templates/donate_cdo/aid/4970020/jewish/Donate.htm

## Run / preview
This is now a static website; it does not need Node.js, Stripe keys, or a backend.

- Extract the ZIP.
- Open `public/index.html` in a browser to preview it.
- To publish it, upload the contents of the `public` folder to the school's approved web host.

## How the donation buttons work
Each sponsorship card and the custom-gift link opens the official Hebrew Academy of Tampa Bay donation page. Donors complete their contribution on that page. This campaign landing page does not collect or process payment details.

## Customize
- Edit sponsorship descriptions and amounts in `public/index.html`.
- Edit colors, layout, and responsive styling in `public/styles.css`.
- Edit mobile navigation behavior in `public/app.js`.

## Before publishing
Have the school's authorized representative approve the campaign text, sponsorship levels, and use of school branding. Confirm that the official donation page is the correct destination and supports the intended mezuzah campaign.


## Main hero image
The homepage hero uses `public/images/school-building.webp`, based on the building illustration supplied for this campaign. Replace that file to use a different hero image.
